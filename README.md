# 🎵 Resso Music - Native Android App

TikTok-style vertical music streaming app with video vibes, synced lyrics, beat effects, and background playback built using Jetpack Compose, Kotlin, ExoPlayer Media3, and Room Database.

---

## 📲 Download APK (Automatic GitHub Action Build)

यह प्रोजेक्ट **GitHub Actions** के साथ पूरी तरह कॉन्फ़िगर किया गया है। हर बार जब आप GitHub पर कोड पुश करेंगे या Actions टैब में जाएंगे, तो यह अपने-आप **Android APK (`Resso-Music.apk`)** बना देगा।

### APK डाउनलोड करने के 3 आसान स्टेप्स:
1. अपने GitHub Repository में जाएँ।
2. ऊपर **Actions** टैब पर क्लिक करें।
3. **Build Android APK** वर्कफ़्लो पर क्लिक करें (या **Run workflow** बटन दबाएँ)।
4. बिल्ड पूरा होने पर (लगभग 2-3 मिनट):
   - **Artifacts** सेक्शन में **`Resso-Music-Android-APK`** पर क्लिक करें।
   - या **Releases** सेक्शन में जाकर सीधे **`Resso-Music.apk`** डाउनलोड करें।
5. डाउनलोड की गई `.apk` फ़ाइल को सीधे अपने Android फ़ोन में इंस्टॉल करें!

## 🚀 Features (Native Android)
- **ExoPlayer & Media3 Playback Service:** Background playback that continues even when the screen is locked or the app is minimized.
- **Lockscreen Media Controls:** Notification drawer controls for Play, Pause, Next, and Previous.
- **Vertical Video Feed:** Seamless music playback with synchronized video vibes.
- **Synced Lyrics:** Dynamic lyrics display synchronized with music timestamps.
- **Local Room Database:** Offline persistence for favorites, history, and custom vibes.
